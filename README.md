Sistema de Gestão de Receitas Médicas

Sistema web para cadastrar, emitir e gerenciar receitas médicas digitais.

Funcionalidades
- Cadastro de médicos, pacientes e medicamentos  
- Emissão e consulta de receitas médicas  
- Histórico de prescrições por paciente  
- Busca por data, nome ou medicamento  
- Controle de acesso por tipo de usuário  

Tecnologias
- *Frontend:* HTML, CSS, JavaScript, Bootstrap  
- *Backend:* Python (Django)  
- *Banco de Dados:* MySQL  

Benefícios
- Redução do uso de papel  
- Facilidade na gestão de receitas  
- Mais segurança na prescrição médica
